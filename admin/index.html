Cấu hình kết nối

Cấu hình Worker và Apps Script sử dụng cho trang quản trị.

Lưu ý bảo mật: Trang này gọi API quản trị từ trình duyệt. Chỉ sử dụng API có xác thực quản trị ở phía máy chủ. Không coi việc ẩn nút hoặc đặt trường nhập mật khẩu trong HTML là biện pháp bảo mật.

Các thao tác quản trị chỉ hoạt động nếu URL Apps Script đang sử dụng đã triển khai phiên bản có các action tương ứng, gồm đọc danh sách tài liệu, Quiz, thiết bị, khóa, mở khóa, xóa thiết bị và thêm dữ liệu.
